# Project Aurora Demo Data

Project Aurora is a fictional smart-city and market simulation initiative. The
same entities appear across the files, API sample, SQL seed script, mail sample
and connector descriptions so keyword search and live RAG can combine evidence
from multiple sources.

Useful demo questions:

- Welche Risiken hat Project Aurora und wer ist dafuer verantwortlich?
- Welche Stadt hat die hoechste erwartete Einsparung?
- Welche Pilotstadt braucht zuerst einen Datenschutz-Review?
- Fasse Budget, Partner und technische Sensoren fuer Project Aurora zusammen.
- Welche offenen Aktionen gibt es vor dem Launch Review?
